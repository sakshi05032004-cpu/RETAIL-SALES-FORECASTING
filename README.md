# Retail Sales Forecasting Using Machine Learning
# Overview
A machine learning project that analyzes historical retail sales data and predicts future sales using Python and ML algorithms. Objectives
Clean and analyze sales data
Perform exploratory data analysis
Create time-based and lag features
Train ML regression models
Forecast future sales
Evaluate model performance
# Technologies
Python,Pandas,NumPy,Scikit-learn,SQL,Power BI
# Models
Linear Regression
Decision Tree
Random Forest
XGBoost
#Evaluation Metrics
MAE
RMSE
R² Score
power BI Dashboard
#Business Use
Helps retailers predict demand, optimize inventory, identify sales trends, and make data-driven decisions.
